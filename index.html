ESOP management system - Microservices Architecture

Tech Stack: Spring Boot, Restful Web Services, Spring Security, Microservices, Kafka, Spring FrameWork(MVC, Web etc...), MySQL via HeidiSQL, SwaggerUI/Postman

This project is divided into smaller parts (microservices). It contains 5 services:

  1. Discovery Gateway (Eureka Server): used for service registration and discovery.
  2. API Gateway (Spring Cloud Gateway): Single entry point, request routing, authentication, and logging.
  3. ESOP Grant Service: Kafka Producer, manages grant data and publishes messages to Kafka.
  4. ESOP Plan Service: Similar to Grant, handles plan data and Can also publish events if needed.
  5. ESOP Allocation Service: Kafka Consumer, listens to grant/plan events, generates allocation numbers, and saves them to the allocation table.
When you run the Grant/Plan services, the data is saved, and then the Allocation Service consumes this data via Kafka, generates allocation numbers, and stores them in the allocation table.

Spring Security is integrated at the gateway and service levels to secure APIs with authentication and authorization.
